## 🏃 Getting Started

### 1. Frontend Client
```bash
cd client
npm install
npm run dev
```
*The client will run on `http://localhost:5173`. Works 100% standalone and can be deployed directly to Vercel, Netlify, or GitHub Pages with zero database configuration.*

### 2. Optional Express Service
```bash
cd server
npm install
npm start
```
